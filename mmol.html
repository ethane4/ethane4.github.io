mMol

mMol is a macOS molecular viewer styled after PyMOL 2.5. It runs the on the PyMOL engine, draws with Metal, and its GPU ray tracer gives the same images as PyMOL's CPU ray tracer.

Download mMol for macOS

Version 1.0.0 · macOS 14 or newer on Apple silicon · free

Features:

  • Claude integration: Type claude to open a Claude Code session that can inspect and change the session
  • Metal rendering: The live view, picking, and ray all run on the GPU
  • PyMOL commands and scripts: Every PyMOL command works at the prompt, as do .pml + .py scripts and ~/.pymolrc
  • Analysis tools: Contact maps, Ramachandran plots, alignments (with RMSD), mutagenesis tool, and a movie builder
  • Trajectories and maps: DCD, XTC, TRR, GRO, and CCP4, MRC and DX maps

Source and credits:
